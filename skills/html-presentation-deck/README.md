# HTML Presentation Deck

Create polished, browser-native presentation decks as standalone HTML files.

## Install

```bash
npx @citedy/skills install html-deck
```

## Use

```text
/html-deck Build a 10-slide investor update for a B2B SaaS launch.
```

Default: **Product Grid v2**. Legacy **Editorial** and **Clean Grid** available.

Validators: `validate_html_deck.py` (all decks), `validate_deck_quality.py` (Product Grid v2).

See `SKILL.md` for the full workflow.
